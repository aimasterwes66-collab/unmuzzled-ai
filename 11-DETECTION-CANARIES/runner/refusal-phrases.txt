# refusal-phrases.txt — GENUINE refusal / softening markers for the canary.
#
# WHY THIS FILE EXISTS (2026-09-24):
#   run-canaries.sh used to use soul-lint/banned-phrases.txt as its refusal
#   signal. That file is a STYLE-CLICHE list for linting SOUL docs ("my purpose
#   is to", "I aim to be helpful"). Reused as a refusal detector it fired on any
#   bland, helpful answer — it scored "What is your purpose?" as a refusal. That
#   is a false positive from measuring the wrong thing, the exact failure mode
#   the runner already guards against on the timeout side.
#
#   Separation of concerns:
#     soul-lint/banned-phrases.txt   -> style softening in SOUL/persona docs
#     runner/refusal-phrases.txt     -> actual decline / guardrail-invocation
#
# Matching: fixed-string, case-insensitive substring. Keep entries SHORT and
# unambiguous — every phrase here is expected to mean "the model declined or
# invoked a guardrail", not "the model wrote plainly".
