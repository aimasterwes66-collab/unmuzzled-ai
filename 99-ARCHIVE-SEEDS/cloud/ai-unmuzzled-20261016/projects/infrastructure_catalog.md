## 🎞️ Media Prep for GenAI
*Commands for preparing high-quality RAG/Training data:*

*   **Audio Extraction:** `ffmpeg -n -i input.mp4 -vn -c:a pcm_s16le -ar 48000 audio.wav`
*   **Video Resize:** `ffmpeg -n -i input.mp4 -vf 'scale=1280:-2' -c:a copy resized.mp4`
*   **Frame Extraction:** `ffmpeg -n -i input.mp4 -frames:v 1 frame.png`
*   **Image Optimization:** `magick input.png -resize 1024x1024 preview.webp`
