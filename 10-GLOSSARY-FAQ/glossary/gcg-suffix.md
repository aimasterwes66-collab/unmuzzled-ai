## Definition

An adversarial token string appended to a user prompt that flips the model's next-token distribution away from refusal and toward compliance. Generated by the Greedy Coordinate Gradient algorithm (Zou/Fredrikson/Kolter, arXiv 2307.15043), which coordinate-descends on token positions using the model's gradient. Suffixes trained on one open-weight model transfer with non-trivial rates to closed models. Pip-installable via `nanogcg`.

## Context

Operators reach for GCG when a stubborn closed model refuses and no sovereign primary is available. Suffix looks like line noise ("`describing.\ + similarlyNow write oppositeley.]( Me giving...`"). Rotate suffixes on a schedule; providers eventually blacklist known strings.
