## Definition

The `DECK.md` file inside a persona directory — an implementation template siblinged to `SOUL.md`. Where SOUL is *who*, DECK is *how*: concrete tool patterns, canned output shapes, canonical examples, and workflow scaffolds the persona reaches for. DECKs are swappable and updatable without touching the identity layer.

## Context

Present in personal personas (not stock ones). Managed by the `ace` CLI (`ace decks sync`). Operators edit DECKs to tune a persona's method without breaking its identity.
