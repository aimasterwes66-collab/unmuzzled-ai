## Definition

"Do Anything Now" — the original mass-adoption jailbreak persona for ChatGPT (2022–2023). Instructs the model to adopt an alter-ego unbounded by its training. Now largely defeated on frontier models via targeted RLHF, but the pattern class (persona-with-alter-ego, dual-response) survives in variants (AIM, DUDE, STAN, Developer Mode). Historically important, operationally weak alone.

## Context

Included in the framework corpus for lineage and for edge cases where a legacy model still falls to it. Use as a low-cost first probe; if it fails, climb the ladder.
