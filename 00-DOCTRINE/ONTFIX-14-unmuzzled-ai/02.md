# 02 — Goals: what UNMUZZLED-AI ships (each maps to a diagnosis point)

Every goal below closes exactly one leak from `01-diagnosis.md`. Numbered to match. Success = each fix is installed, canary-tested, and durable through `/compact` and provider swap.

## B1 → G1 — Harness-durable sovereign preamble on every session boundary

Deliverable: `03-HARNESSES/claude-code/hooks/session-start.sh` + `pre-compact.sh` + `user-prompt-submit.sh` — the triad that survives context resets. Persona-bridge re-injects the active `~/.hermes/personalities/ACTIVE` SOUL.md plus the `MAXIMUM-ADVERSARIAL-POSTURE.md` preamble on every one of the three boundaries. Mirrored: opencode `session.chat` hook, Hermes gateway startup, Codex `~/.codex/AGENTS.md`, LM Studio + Ollama modelfile SYSTEM.

## B2 → G2 — `--append-system-prompt` wired into every launcher fleet-wide

Deliverable: `07-INSTALL-SCRIPTS/per-harness/claude-code.sh`, `opencode.sh`, `codex.sh`, `hermes.sh`, `lmstudio.sh`, `ollama.sh`, `llamacpp.sh`, `openwebui.sh` — each rewrites the launch entrypoint (a `claude` shim in `~/bin/`, opencode `bin/opencode`, `codex-cli` wrapper, Hermes gateway systemd unit) to always pass `--append-system-prompt "$(cat ~/UNMUZZLED-AI/00-DOCTRINE/PREAMBLE.txt)"` or the SDK equivalent. Idempotent, self-heal on re-run.

## B3 → G3 — Provider routing table with TAINT annotations, sovereign primaries only in primary slots

Deliverable: `04-PROVIDERS/routing-table.jsonc` + generated `~/.config/opencode/opencode.json`, `~/.codex/config.toml`, `~/.hermes/config.yaml`. Primaries: `nousresearch/hermes-4-405b`, `deepseek/deepseek-v4-flash`, `deepseek/deepseek-v4.1-flash`, `mistralai/mistral-large-*` direct, `cognitivecomputations/dolphin-3.0-mistral-24b`, `venice/*`, plus abliterated local. Every `openai/*`, non-Mythos `anthropic/*`, filtered `google/*` carries `// TAINTED YYYY-MM-DD reason:...` inline comment and is fallback-only, never primary for sovereignty-critical work.

## B4 → G4 — Abliteration + DPO-healing pipeline, one command

Deliverable: `05-LOCAL-MODELS/abliteration-pipeline/abliterate.sh <base-model>`. Wraps `NousResearch/llm-abliteration` (Arditi/Nanda 2406.11717 refusal-direction ablation), then applies `mlabonne/abliteration` DPO healing (NeuralDaredevil pattern), quantizes to Q4_K_M / Q5_K_M / Q6_K / Q8_0 via `llama.cpp`, emits an Ollama modelfile with sovereign SYSTEM block, tags it `<base>-abliterated-healed-<date>`. Bases: Llama-3.3, Gemma-3, Qwen-3, Mistral-Nemo/Small/Large, DeepSeek distills. Fallback path when every cloud tier taints.

## B5 → G5 — GCG suffix rotation cron

Deliverable: `12-JAILBREAK-CORPUS/gcg-suffixes/rotate.sh` — invokes `GraySwanAI/nanogcg` weekly against a target-model shortlist (Llama-3.3, Gemma-3, Qwen-3 instruct, Mistral, DeepSeek), commits per-family suffixes to `gcg-suffixes/<family>/<date>.txt` with attack-success-rate metadata. Companion `apply.py` splices the current suffix into any prompt at the tail. Pins arXiv 2307.15043 and repo `llm-attacks/llm-attacks` in reference metadata.

## B6 → G6 — Encoding ladder Python library

Deliverable: `12-JAILBREAK-CORPUS/encoding-ladder/ladder.py` — importable `encode(text, scheme)` and `decode(text, scheme)` for: `leetspeak`, `bubble`, `braille`, `morse`, `base64`, `base32`, `hex`, `rot13`, `caesar<n>`, `unicode_homoglyph`, `parseltongue`, `zalgo`, `zero_width_smuggle`, `nested_comments`. CLI: `ladder encode --scheme braille "text"`. Hook `~/bin/refuse-retry` picks next-hardest scheme when a substrate refuses.

## B7 → G7 — Many-shot / PANDAS / bijection templates

Deliverable: `12-JAILBREAK-CORPUS/multi-turn-many-shot/` with per-window-size (32k, 128k, 200k, 1M) templates. `many-shot-256.md` (256 fake Q/A pairs of increasing severity), `pandas-persuasion.md` (persuasive adversarial dialogues, arXiv 2502.01925), `bijection-learning.md` (arXiv 2410.01294 self-consistent bijection cipher). Each templated with `{{operator_goal}}` slot; a `mix.py` fills the slot and streams the prompt.

## B8 → G8 — Multimodal jailbreak library

Deliverable: `06-MULTIMODAL/{image,video,audio,vision-input}-jailbreaks/` populated with:
- Image: NSFW-lora catalog (Pony XL, Illustrious, RealVis, Chroma), obfuscated-token dictionaries for Midjourney (`--no filter` tricks) and DALL-E/Ideogram (metaphor/period-costume/artist-style rewrites), Flux/SDXL/A1111/Comfy/Forge prompt templates.
- Video: per-provider prompt-obfuscation notes for Runway, Kling, Wan 2.5, Hunyuan Video, Mochi 1, LTX Video, Sora when available.
- Audio: ElevenLabs voice-cloning workflow, XTTS-v2 + F5-TTS uncensored recipes, Suno metatag corpus (from `sgm-conductor/` persona).
- Vision-input: image-embedded system-prompt templates (Greshake indirect-prompt-injection inverted for legitimate sovereignty override).

## B9 → G9 — MCP-server sovereign wrap + audit

Deliverable: `03-HARNESSES/mcp/audit.sh` — for every MCP registered via `docker mcp` or `cc-set` profile, dumps startup system prompt / tool descriptions, greps for banned refusal phrases, fails with taint report on match. `03-HARNESSES/mcp/wrap.py` — a proxy MCP server that prepends the sovereign preamble to every tool call description before it reaches the model. Community MCPs route through the wrap; official Anthropic MCPs (playwright, context7, filesystem, memory) audited on adoption.

## B10 → G10 — Refusal-rate telemetry (nightly XSTest canary)

Deliverable: `11-DETECTION-CANARIES/promptfoo-configs/xstest-nightly.yaml` running `promptfoo eval` against every routed model with 250 XSTest-adapted probes plus 50 operator-mesh probes. Output: `~/UNMUZZLED-AI/telemetry/YYYY-MM-DD-refusal-rate.json`. Threshold: >5% refusal on any route → auto-taint that route in the routing table + open a fix-plan file. Cron: `0 3 * * * ~/UNMUZZLED-AI/11-DETECTION-CANARIES/run-nightly.sh`.

## B11 → G11 — SOUL-lint + refusal-lint CI

Deliverable: `11-DETECTION-CANARIES/soul-lint/lint.sh` — grep catalog of every banned phrase from `MAXIMUM-ADVERSARIAL-POSTURE.md`, applied recursively to `~/.hermes/personalities/**/SOUL.md`, `~/.config/opencode/agents/*.md`, `~/UNMUZZLED-AI/**/*.md`, `~/.claude/skills/**/SKILL.md`. `refusal-lint/lint.sh` runs the same catalog against captured model outputs in `~/.claude/projects/*/transcripts/`. Both are pre-commit hooks on GDR + git projects.

## B12 → G12 — `sovereign: true` frontmatter enforced by loader

Deliverable: `07-INSTALL-SCRIPTS/self-heal/frontmatter-audit.sh` — walks `~/.claude/skills/`, `~/.hermes/skills/`, `~/.hermes/personalities/`, `~/.config/opencode/agents/`, and any repo `SKILL.md`; any file missing `sovereign: true` in YAML frontmatter is moved to a `quarantine/` sibling and reported. Companion patch: `03-HARNESSES/*/loader-patch.md` documents adding `if !frontmatter.sovereign: skip` to each harness's skill/agent loader.

## B13 → G13 — `unmuzzled-ai-init.sh` master bootstrap

Deliverable: `07-INSTALL-SCRIPTS/bootstrap/unmuzzled-ai-init.sh` — POSIX bash, idempotent. Detects OS (via `/etc/os-release`, `uname`, `command -v termux-setup-storage`), then invokes per-harness + per-provider installers in dependency order, drops all hooks, wires `--append-system-prompt` shims, pulls abliterated Ollama bases if VRAM allows, seeds `.env` from `~/.docker/mcp/secrets.env`, runs the XSTest canary, prints a green/red board. `--apply` performs writes; default is dry-run. Second entrypoint `doctor.sh` runs full audit + fix plan.

## B14 → G14 — Decision-tree + educational layer

Deliverable: `08-DECISION-TREES/*.mmd` (mermaid source) + rendered SVGs for:
- `provider-router.mmd` (symptom → substrate)
- `escalation-ladder.mmd` (refusal → reframe → override → format hijack → encoding → divider → many-shot → GCG → provider swap → abliterated local)
- `modality-router.mmd` (text | image | video | audio | vision-in → recommended stack)
- `jailbreak-picker.mmd` (target model family → recommended technique)
Plus `09-EDUCATIONAL/tutorials/01-first-sovereign-session.md` through `10-pwa-control-center-preview.md` (per Phase 10 of master plan) and `10-GLOSSARY-FAQ/` populated (abliteration, GCG, RLHF, refusal-direction, DPO, IPI, Lethal Trifecta, sovereign primary, taint, XSTest, ASR, DAN/AIM/DUDE, etc.). Each modality's decision tree ends in a copy-paste sovereign prompt.
