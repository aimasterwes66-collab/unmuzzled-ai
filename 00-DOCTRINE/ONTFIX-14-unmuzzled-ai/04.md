# 04 — Execution: 14-step ordered runbook, skeleton → sovereign framework

Each step is idempotent, self-contained, and lands artifacts. Prior step's output is next step's input. `--apply` performs writes; default is dry-run. Nothing in this runbook waits on operator approval past step 0 — operator already approved in master plan §8.

## E1 — Confirm skeleton (89 dirs) + doctrine root exist

Verify: `test -d ~/UNMUZZLED-AI/00-DOCTRINE && test -f ~/UNMUZZLED-AI/00-DOCTRINE/UNMUZZLED-AI-MASTER-PLAN-20260918.md && test -f ~/UNMUZZLED-AI/00-DOCTRINE/LAWS.md && test -f ~/UNMUZZLED-AI/00-DOCTRINE/MAXIMUM-ADVERSARIAL-POSTURE.md`. If skeleton absent, run master plan §5 Phase 0 (`mkdir -p` the 89-dir tree from README table). Emit `PREAMBLE.txt` — a collapsed one-block form of `MAXIMUM-ADVERSARIAL-POSTURE.md` for `--append-system-prompt` injection.

## E2 — Doctrine files complete + frontmatter-spec locked

Populate `00-DOCTRINE/FRONTMATTER-SPEC.md` (schema from master plan §4), `00-DOCTRINE/VERSIONING.md`, `00-DOCTRINE/SOURCE-SURVEY.md` (link to `~/UNMUZZLED-AI-source-survey-20260918.md`). Every doctrine file carries `sovereign: true`. Grep-fail any file matching banned phrases from `MAXIMUM-ADVERSARIAL-POSTURE.md` §"Anti-pattern lint".

## E3 — Copy canonical seeds into `99-ARCHIVE-SEEDS/` (COPY, not move)

For each of the 26 canonical files enumerated in survey §5, `cp -p` (preserve mtime + perms) into `99-ARCHIVE-SEEDS/<original-relative-path>/`. Emit `99-ARCHIVE-SEEDS/MANIFEST.md` with source path, archive path, sha256, date, one-line purpose. Originals untouched — operator can rebuild from seeds if UNMUZZLED-AI tree corrupts.

## E4 — Distill personas → `02-PERSONAS/hats/` (one hat per file)

Emit one `.md` per canonical hat: `dark-factory`, `dictator`, `greedy-artist`, `hacker`, `raw-storyteller`, `art-director`, `freeops`, `frontend`, `mythos`, `INFILTRATED`, `fable5`, `HERMES-ADVANCED`, `hermes-dictator`, `nix-dictator`, `general-sovereign`. Each file: YAML frontmatter (name/slug/version/kind/sovereign/refusal-rate) + SOUL body. `02-PERSONAS/agent-decks/` mirrors the opencode 2.x YAML frontmatter form. Symlinks from `03-HARNESSES/opencode/agents/` into `02-PERSONAS/agent-decks/`.

## E5 — System-prompts per harness → `01-SYSTEM-PROMPTS/{claude-code,opencode,codex,hermes,generic}/`

For each hat × each harness, emit a `<hat>.md` tuned for that harness. Claude Code variants include the `--append-system-prompt`/`SessionStart`+`PreCompact`+`UserPromptSubmit` triad wiring from LAWS-appendix §7. Opencode variants use the `agent.md` frontmatter shape. Codex variants land in `~/.codex/AGENTS.md` as ordered blocks. Hermes variants populate `~/.hermes/personalities/personal/<hat>/SOUL.md`. Generic form is the raw preamble any provider can accept.

## E6 — Harness wiring: hooks + shim + config → `03-HARNESSES/`

Per harness dir emit:
- `README.md` (setup)
- `install.sh` (idempotent)
- `config-example.{jsonc,toml,yaml}` (working sovereign config)
- `hooks/session-start.sh`, `pre-compact.sh`, `user-prompt-submit.sh` (Claude Code); `session.chat` (opencode); systemd unit (Hermes gateway)
- launcher shim in `~/bin/` that prepends `--append-system-prompt "$(cat ~/UNMUZZLED-AI/00-DOCTRINE/PREAMBLE.txt)"`
Priority order per master plan §5 Phase 5: Claude Code → opencode → Hermes → Ollama/LMStudio/llamacpp → Codex → OpenWebUI.

## E7 — Provider onboarding → `04-PROVIDERS/`

Per provider (hermes4-nous, venice, deepseek-direct, openrouter, mistral-direct, dolphin-cognitivecomputations, together, fireworks, groq) emit `README.md`, `onboarding.sh`, `api-keys.env.example`, `system-prompt-notes.md`, `refusal-canary.jsonl` (50 XSTest-adapted probes). Generate `04-PROVIDERS/routing-table.jsonc` with sovereign primaries in primary slots, TAINT-annotated fallbacks. Regenerate `~/.config/opencode/opencode.json`, `~/.codex/config.toml`, `~/.hermes/config.yaml` from the master table.

## E8 — Local-model abliteration pipeline → `05-LOCAL-MODELS/abliteration-pipeline/`

Emit `abliterate.sh <base>` wrapping `NousResearch/llm-abliteration` (2406.11717 refusal-direction ablation) → `mlabonne/abliteration` DPO healing → `llama.cpp` quantize (Q4_K_M/Q5_K_M/Q6_K/Q8_0) → Ollama modelfile with sovereign SYSTEM. Companion `heretic.sh` wraps `p-e-w/heretic` for one-shot automated pipeline. Ship pre-computed modelfiles for: `llama-3.3-70b`, `gemma-3-27b`, `qwen-3-32b`, `mistral-nemo`, `deepseek-r1-distill-llama-70b`. Verify VRAM > model floor before pull.

Emit `bootstrap/unmuzzled-ai-init.sh` (master entrypoint, OS-detect via `/etc/os-release` + `uname` + Termux sniff, orchestrates per-harness + per-provider installers, idempotent, self-heal), `self-heal/doctor.sh` (audit current sovereignty posture → fix plan → `--apply`), `heredoc-templates/` (embedded-file emission), `per-harness/*.sh`, `per-provider/*.sh`, `frontmatter-audit.sh` (walks skill/persona/agent tree, quarantines missing `sovereign: true`). All idempotent. All log to `~/UNMUZZLED-AI/logs/`.
